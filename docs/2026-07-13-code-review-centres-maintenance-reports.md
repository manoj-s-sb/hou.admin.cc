## Cross-cutting themes

1. **Facility scoping is inconsistent across modules.** Centres (role-based) and Maintenance (route param) are correct; **Reports has none**. Pick one contract (`getFacilityCode()`) and apply it everywhere, or explicitly RBAC-gate the exceptions. _(This is the single most important theme.)_
2. **Blob upload has no `res.ok` check** (`uploadFileToBlob`) — one shared helper, affects Maintenance **and** Tickets. Silent upload failures produce dangling blob references. Highest-value single fix.
3. **Oversized files:** `NewCentreWizard.tsx` (1843), `index.tsx` maintenance (509), `MembershipReportPdf.tsx` (397). All work, all hard to change safely. Split when next touched.
4. **UTC vs local date handling** appears in both maintenance (schedule "today") and reports (report id/date) — standardize on one date helper.
5. **Dead code** in each module (maintenance `getTemplate` + constants re-exports + `saving`/`error` slice fields; reports unused props; centres dead context state). Small, safe cleanups.

## Suggested priority order

1. `uploadFileToBlob` `res.ok` check (Maintenance + Tickets) — HIGH, tiny, high-value.
2. Maintenance reschedule atomicity — HIGH, data-loss risk.
3. Reports facility scoping / RBAC gate — HIGH, correctness + possible data exposure.
4. Centres: scope or hide Induction/Tours; add role guard to the centre route.
5. Structure splits (wizard, maintenance index) — schedule as refactors, not urgent.
6. Dead-code sweep — quick win.
